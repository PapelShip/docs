## Почніть розробку

<Steps>
  <Step title="Отримайте API-ключ">
    Увійдіть до [панелі керування PapelShip](https://app.papelship.com) і створіть API-ключ для свого магазину.
  </Step>
  <Step title="Надішліть перший запит">
    Скористайтеся [швидким стартом](/uk/quickstart), щоб створити перше замовлення та перенаправити клієнта на оформлення.
  </Step>
  <Step title="Запуск у робочому режимі">
    Перед запуском ознайомтеся з розділами [автентифікація](/uk/guides/authentication), [помилки](/uk/guides/errors) та [ідемпотентність](/uk/guides/idempotency).
  </Step>
</Steps>

## Базові URL

| API | Базовий URL |
| :-- | :-- |
| User API | `https://app.papelship.com/api/v1` |
| qPapel Protection | `https://app.papelship.com/api/qpapel/v1` |

<Info>
  Усі API приймають і повертають JSON через HTTPS. Запити через звичайний HTTP не підтримуються.
</Info>
