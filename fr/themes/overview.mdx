Les vitrines PapelShip peuvent être créées visuellement, en code, ou les deux. Vous modifiez tout dans le panneau de la boutique, sous **Themes**, et chaque modification de code passe par le même éditeur de code, le même historique des versions et le même scanner de sécurité.

## Copies de thème

Chaque thème Liquid, design et paquet de code de thème est une **copie** de votre boutique. Une boutique peut conserver jusqu'à 20 copies.

- Les modifications sont enregistrées dans la copie que vous modifiez. Une copie qui n'est pas en ligne ne modifie jamais votre vitrine.
- La copie en ligne ne change que lorsque vous la publiez ou l'activez dans le panneau.
- Chaque enregistrement conserve une version. Vous pouvez restaurer n'importe laquelle des 50 dernières versions d'un fichier.

| Limite | Valeur |
| --- | --- |
| Taille d'un fichier | 512 Ko |
| Fichiers par copie | 400 |
| Taille d'une copie | 10 Mo |
| Copies par boutique | 20 |

## Aperçus

Les aperçus affichent vos fichiers enregistrés et vos brouillons non enregistrés de l'éditeur dans le panneau. Ils ne sont jamais publics : la vitrine n'affiche une copie qui n'est pas en ligne que dans le cadre d'aperçu du panneau, avec un jeton signé qui expire au bout de 30 minutes.

## Travailler avec un agent IA

Connectez Claude, Cursor, VS Code ou un autre client MCP à vos thèmes. L'agent lit le code de votre thème et enregistre ses modifications sous forme de brouillons ; vous les examinez et les publiez. Consultez [Agents IA (MCP)](/fr/themes/mcp).
