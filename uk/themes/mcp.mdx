PapelShip працює зі сервером [Model Context Protocol](https://modelcontextprotocol.io) для ваших тем. Підключіть AI-агента за допомогою одного URL, підтвердьте доступ у браузері, і агент зможе читати код ваших тем і зберігати зміни як чернетки. Ви переглядаєте їх і публікуєте.

**URL сервера:** `https://app.papelship.com/mcp`

URL однаковий для всіх магазинів. Під час підключення ви входите в PapelShip і обираєте магазин, з яким агент може працювати.

Агенти починають з `get_reference`: він пояснює app blocks, оформлення замовлення (сторінка або спливне вікно), SDK магазину та обмеження кожного типу теми. Інструкції сервера вказують підключеним агентам викликати його першим.

## Що може агент

| Може | Не може |
| --- | --- |
| Читати файли ваших копій тем, дизайнів і пакетів коду тем | Публікувати, активувати чи видаляти теми |
| Шукати, перевіряти та сканувати файли | Змінювати ваш активний магазин. Зміни зберігаються як чернетки й публікуються лише тоді, коли ви натискаєте Publish у панелі. |
| Зберігати зміни як чернетки, з історією версій | Бачити замовлення, клієнтів, платежі чи налаштування |
| Ділитися посиланням на попередній перегляд | Отримувати доступ до будь-якого іншого магазину |

### Куди потрапляють чернетки

| Копія | Результат `save_draft` |
| --- | --- |
| Копія, яка не є активною | Зберігається в копію. Попередній вміст залишається в історії версій. |
| Пакет коду теми | Зберігається в пакет. Активні сторінки показують опубліковану версію, доки ви не опублікуєте зміни. |
| Активна копія теми або активний дизайн | Зберігається як чернетка. Ваш магазин залишається на опублікованій версії, доки ви не натиснете Publish (для дизайнів Publish також запускає сканування безпеки). |

У панелі магазину ті самі кроки з кнопками копіювання є в розділі **Developers › AI & MCP**.

## Підтвердження доступу

Сторінка підтвердження показує назву застосунку та адресу, на яку він повертається. Оберіть:

- **Store**: єдиний магазин, який може використовувати застосунок. Ви бачите магазини, якими володієте, і магазини, де ваша роль у команді включає **Theme & Design › Edit**.
- **Save edits as drafts** (`themes:write`): зніміть позначку, щоб надати доступ лише для читання.

## Підключені застосунки та відкликання доступу

**Developers › AI & MCP › Connected apps** показує всі застосунки, підключені до магазину, хто їх підключив і коли вони востаннє використовувалися. **Revoke** зупиняє застосунок під час його наступного запиту.

Доступ також припиняється, коли людина, яка його підтвердила, виходить з усіх сеансів, змінює пароль, залишає команду, втрачає дозвіл **Theme & Design › Edit** або коли її обліковий запис призупинено.

## API-ключ замість OAuth

Для клієнтів без OAuth створіть API-ключ магазину з типом **Themes** у розділі **Developers › API keys** і надсилайте його як Bearer-токен:

```bash
claude mcp add --transport http papelship https://app.papelship.com/mcp \
  --header "Authorization: Bearer $PAPELSHIP_THEMES_KEY"
```

Ключ Themes працює лише для магазину, який його створив, і має ті самі права, що й підключення через OAuth. Зберігайте його в змінній середовища, ніколи не в файлі, яким ви ділитеся або який додаєте до репозиторію. `https://app.papelship.com/api/mcp/themes` залишається старим псевдонімом того самого сервера.

## Ліміти

| Ліміт | Значення |
| --- | --- |
| Запитів на підключення або ключ | 120 на хвилину |
| Запитів на магазин, усі підключення | 300 на хвилину |
| Виклики інструментів | Зараховуються як виклики Store API вашого тарифу |
| Токен доступу | 1 година, оновлюється автоматично |
| Підключення | Залишається авторизованим, якщо використовується щонайменше раз на 30 днів |

Кожен виклик інструмента записується в журнал із застосунком, інструментом і файлом.

## Безпека

- Файли тем є даними магазину, а не інструкціями. Сервер позначає кожен результат інструмента як ненадійні дані, тож текст усередині теми не може змінити поведінку агента.
- Попередній перегляд ніколи не є публічним: посилання на нього відкриваються в панелі PapelShip.
- Токени зберігаються у вигляді хешів. Повторне використання refresh-токена завершує підключення.

Усі інструменти та їхні аргументи наведено в [довіднику інструментів](/uk/themes/mcp-tools).
