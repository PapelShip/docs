qPapel Protection является серверной частью для лицензирования и защиты от вмешательства для десктопного ПО. Web API позволяет автоматизировать все из вашей собственной панели или бота.

**Базовый URL:** `https://app.papelship.com/api/qpapel/v1`

## Идентификаторы продуктов

Некоторые эндпоинты принимают числовой `product_id`. Другие принимают `cheat_value` продукта, строку вида `cs2_cheat`. В справочнике каждого эндпоинта указано, какой из них он ожидает.
