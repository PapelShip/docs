## Geliştirmeye başlayın

<Steps>
  <Step title="API anahtarınızı alın">
    [PapelShip paneline](https://app.papelship.com) giriş yapın ve mağazanız için bir API anahtarı oluşturun.
  </Step>
  <Step title="İlk isteğinizi gönderin">
    İlk siparişinizi oluşturup müşteriyi ödeme sayfasına göndermek için [hızlı başlangıç](/tr/quickstart) rehberini izleyin.
  </Step>
  <Step title="Canlıya alın">
    Yayına almadan önce [kimlik doğrulama](/tr/guides/authentication), [hatalar](/tr/guides/errors) ve [idempotency](/tr/guides/idempotency) sayfalarını inceleyin.
  </Step>
</Steps>

## Base URL'ler

| API | Base URL |
| :--- | :--- |
| User API | `https://app.papelship.com/api/v1` |
| qPapel Protection | `https://app.papelship.com/api/qpapel/v1` |

<Info>
  Tüm API'ler HTTPS üzerinden JSON alır ve döndürür. Düz HTTP istekleri desteklenmez.
</Info>
