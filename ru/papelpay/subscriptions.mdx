Товар с включенными подписками и заданным расчетным периодом можно купить по подписке. Когда клиент платит через PapelPay, оплата с карты списывается снова каждый период, пока он не отменит подписку. При любом другом способе оплаты клиент получает по email счет на продление перед окончанием каждого периода. На этой странице показано, как управлять этим выбором через Store API.

## Выберите подписку или разовую покупку

Передайте `auto_renew` при создании заказа:

| Значение | Результат |
| :-- | :-- |
| `true` | Заказ покупается как подписка. Клиент не может отключить ее при оформлении заказа. |
| `false` | Заказ является разовой покупкой. Страница оплаты не показывает вариант с подпиской. |
| Не передано | Клиент выбирает при оформлении заказа. Подписка выбрана по умолчанию. |

```bash
curl -X POST https://app.papelship.com/api/v1/invoices \
  -H "x-api-key: pk_live_your_key" \
  -H "x-store-hash: your_store_id" \
  -H "Idempotency-Key: WEB-2087" \
  -H "Content-Type: application/json" \
  -d '{
    "customer_email": "buyer@example.com",
    "items": [{ "product_id": "Pr0Mnth1yX9a" }],
    "auto_renew": true,
    "payment_method": "PAPELPAY"
  }'
```

Для `auto_renew: true` нужен заказ ровно с одной товарной позицией, и у этого товара должны быть включены подписки с расчетным периодом. Иначе вызов завершится ошибкой `SUBSCRIPTION_NOT_AVAILABLE` (`422`), и заказ не будет создан.

## Объект подписки

Ответы на создание и получение заказа содержат `subscription`. Он равен `null`, если заказ не может быть подпиской.

```json
"subscription": {
  "enabled": true,
  "locked": true,
  "interval_days": 30,
  "interval": "month",
  "discount_percent": 20,
  "discount_applies_to": "automatic_payments",
  "discount_cents": 0,
  "subscription_id": null,
  "auto_renewal_id": null
}
```

| Поле | Значение |
| :-- | :-- |
| `enabled` | `true`: куплен как подписка. `false`: разовая покупка. |
| `locked` | Задается через `auto_renew` при создании. Клиент не может изменить его при оформлении заказа. |
| `interval_days`, `interval` | Расчетный период. `interval` принимает значения `day`, `week`, `month` или `year` для стандартных периодов, иначе `null`. |
| `discount_percent` | Скидка для подписчиков, заданная в товаре. |
| `discount_applies_to` | `automatic_payments`: только при автоматическом продлении с карты. `all_payment_methods`: при любом способе оплаты. |
| `discount_cents` | Скидка, уже включенная в `total_cents`. Остается `0`, пока клиент не выберет способ оплаты, к которому она применяется. |
| `subscription_id` | После оплаты: запись подписки. |
| `auto_renewal_id` | После оплаты картой через PapelPay: автоматическое продление по карте. |

## После оплаты

Первый платеж завершает заказ и запускает подписку. Каждое продление создает новый оплаченный заказ и продлевает подписку. Просматривайте и останавливайте подписки с помощью этих эндпоинтов:

| Действие | Эндпоинт |
| :-- | :-- |
| Список подписок | `GET /subscriptions` |
| Получить одну подписку с ее платежами | `GET /subscriptions/{subscriptionId}` |
| Отменить | `POST /subscriptions/{subscriptionId}/cancel` |
| Список автоматических продлений по карте | `GET /subscriptions/auto-renewals` |
| Остановить будущие списания с карты | `POST /subscriptions/auto-renewals/{renewalId}/cancel` |

Остановка автоматического продления прекращает будущие списания в конце оплаченного периода. Отмена никогда не возвращает деньги клиенту.

<Note>
  Оплата подписок картой списывается в USD.
</Note>
