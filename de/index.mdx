## Mit der Entwicklung beginnen

<Steps>
  <Step title="API-Schlüssel abrufen">
    Melden Sie sich im [PapelShip Dashboard](https://app.papelship.com) an und erstellen Sie einen API-Schlüssel für Ihren Shop.
  </Step>
  <Step title="Ersten Request senden">
    Folgen Sie dem [Schnellstart](/de/quickstart), um Ihre erste Bestellung zu erstellen und den Kunden zum Checkout weiterzuleiten.
  </Step>
  <Step title="Live gehen">
    Lesen Sie [Authentifizierung](/de/guides/authentication), [Fehler](/de/guides/errors) und [Idempotenz](/de/guides/idempotency), bevor Sie live gehen.
  </Step>
</Steps>

## Basis-URLs

| API | Basis-URL |
| :-- | :-- |
| User API | `https://app.papelship.com/api/v1` |
| qPapel Protection | `https://app.papelship.com/api/qpapel/v1` |

<Info>
  Alle APIs akzeptieren und liefern JSON über HTTPS. Requests über einfaches HTTP werden nicht unterstützt.
</Info>
