This guide takes you through a full order with the PapelShip Store API: create an order for one of your products, send the customer to the hosted checkout, and confirm the payment before you rely on it.

## Prerequisites

- A PapelShip store with at least one product
- A Store API key (`pk_live_...`) with the `orders:write` permission, and your store ID for the `x-store-hash` header

<Tip>
  You find both in the [PapelShip dashboard](https://app.papelship.com) under your store's API settings. See [Authentication](/en/guides/authentication).
</Tip>

<Steps>
  <Step title="Create an order">
    Send the customer's email and the products. Add an `Idempotency-Key` header so retries never create a second order.

    <CodeGroup>
    ```bash cURL
    curl -X POST https://app.papelship.com/api/v1/invoices \
      -H "x-api-key: pk_live_your_key" \
      -H "x-store-hash: your_store_id" \
      -H "Idempotency-Key: WEB-1042" \
      -H "Content-Type: application/json" \
      -d '{
        "customer_email": "buyer@example.com",
        "items": [{ "product_id": "a1B2c3D4e5F6", "quantity": 1 }],
        "metadata": { "order_ref": "WEB-1042" }
      }'
    ```

    ```javascript Node.js
    const res = await fetch("https://app.papelship.com/api/v1/invoices", {
      method: "POST",
      headers: {
        "x-api-key": process.env.PAPELSHIP_API_KEY,
        "x-store-hash": process.env.PAPELSHIP_STORE_ID,
        "Idempotency-Key": order.id,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        customer_email: order.email,
        items: [{ product_id: "a1B2c3D4e5F6", quantity: 1 }],
        metadata: { order_ref: order.id },
      }),
    });
    const { invoice } = await res.json();
    ```

    ```python Python
    import os, requests
    
    res = requests.post(
        "https://app.papelship.com/api/v1/invoices",
        headers={
            "x-api-key": os.environ["PAPELSHIP_API_KEY"],
            "x-store-hash": os.environ["PAPELSHIP_STORE_ID"],
            "Idempotency-Key": order_id,
        },
        json={
            "customer_email": "buyer@example.com",
            "items": [{"product_id": "a1B2c3D4e5F6", "quantity": 1}],
            "metadata": {"order_ref": order_id},
        },
    )
    invoice = res.json()["invoice"]
    ```
    </CodeGroup>
  </Step>

  <Step title="Send the customer to checkout">
    The response contains the order with its `checkout_url`. Redirect the customer there to pay with any method your store accepts.

    ```json Response (201)
    {
      "success": true,
      "invoice": {
        "id": "c35ffd-19a1b2c3d4e-8c7a20",
        "status": "pending",
        "currency": "USD",
        "total_cents": 3499,
        "checkout_url": "https://invoice.papelship.com/c35ffd-19a1b2c3d4e-8c7a20",
        "expires_at": "2026-10-04T15:00:00.000Z"
      }
    }
    ```

    Store `invoice.id` with your order. Unpaid orders expire after 3 hours. To charge a card right away, or to show the card form on your own site, see [PapelPay](/en/papelpay/overview).
  </Step>

  <Step title="Confirm the payment">
    Never trust the customer's return to your site alone. Listen for the `order.completed` webhook, or read the order on your server:

    ```bash
    curl https://app.papelship.com/api/v1/invoices/c35ffd-19a1b2c3d4e-8c7a20 \
      -H "x-api-key: pk_live_your_key" \
      -H "x-store-hash: your_store_id"
    ```

    The order is paid and delivered when `status` is `completed`.
  </Step>
</Steps>

<Warning>
  Keep your API key on your server. Never ship it in browser code, mobile apps, or desktop clients.
</Warning>
