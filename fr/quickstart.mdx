---
title: "Démarrage rapide"
description: "Créez votre première commande avec la Store API PapelShip, redirigez le client vers le paiement, puis confirmez le paiement par webhook ou en lisant la commande."
---

Ce guide vous accompagne tout au long d'une commande complète avec la Store API PapelShip : créer une commande pour l'un de vos produits, rediriger le client vers la page de paiement hébergée, puis confirmer le paiement avant de vous y fier.

## Prérequis

- Une boutique PapelShip avec au moins un produit
- Une clé Store API (`pk_live_...`) disposant de l'autorisation `orders:write`, et l'identifiant de votre boutique pour l'en-tête `x-store-hash`

<Tip>
  Vous trouverez les deux dans le [tableau de bord PapelShip](https://app.papelship.com), dans les paramètres API de votre boutique. Consultez [Authentification](/fr/guides/authentication).
</Tip>

<Steps>
  <Step title="Créer une commande">
    Envoyez l'e-mail du client et les produits. Ajoutez un en-tête `Idempotency-Key` afin que les nouvelles tentatives ne créent jamais de seconde commande.

    <CodeGroup>

    ```bash cURL
    curl -X POST https://app.papelship.com/api/v1/invoices \
      -H "x-api-key: pk_live_your_key" \
      -H "x-store-hash: your_store_id" \
      -H "Idempotency-Key: WEB-1042" \
      -H "Content-Type: application/json" \
      -d '{
        "customer_email": "buyer@example.com",
        "items": [{ "product_id": "a1B2c3D4e5F6", "quantity": 1 }],
        "metadata": { "order_ref": "WEB-1042" }
      }'
    ```

    ```javascript Node.js
    const res = await fetch("https://app.papelship.com/api/v1/invoices", {
      method: "POST",
      headers: {
        "x-api-key": process.env.PAPELSHIP_API_KEY,
        "x-store-hash": process.env.PAPELSHIP_STORE_ID,
        "Idempotency-Key": order.id,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        customer_email: order.email,
        items: [{ product_id: "a1B2c3D4e5F6", quantity: 1 }],
        metadata: { order_ref: order.id },
      }),
    });
    const { invoice } = await res.json();
    ```

    ```python Python
    import os, requests
    
    res = requests.post(
        "https://app.papelship.com/api/v1/invoices",
        headers={
            "x-api-key": os.environ["PAPELSHIP_API_KEY"],
            "x-store-hash": os.environ["PAPELSHIP_STORE_ID"],
            "Idempotency-Key": order_id,
        },
        json={
            "customer_email": "buyer@example.com",
            "items": [{"product_id": "a1B2c3D4e5F6", "quantity": 1}],
            "metadata": {"order_ref": order_id},
        },
    )
    invoice = res.json()["invoice"]
    ```

    </CodeGroup>
  </Step>
  <Step title="Rediriger le client vers le paiement">
    La réponse contient la commande avec son `checkout_url`. Redirigez-y le client pour qu'il paie avec l'un des moyens de paiement acceptés par votre boutique.

    ```json Réponse (201)
    {
      "success": true,
      "invoice": {
        "id": "c35ffd-19a1b2c3d4e-8c7a20",
        "status": "pending",
        "currency": "USD",
        "total_cents": 3499,
        "checkout_url": "https://invoice.papelship.com/c35ffd-19a1b2c3d4e-8c7a20",
        "expires_at": "2026-10-04T15:00:00.000Z"
      }
    }
    ```

    Enregistrez `invoice.id` avec votre commande. Les commandes impayées expirent au bout de 3 heures. Pour débiter une carte immédiatement, ou pour afficher le formulaire de carte sur votre propre site, consultez [PapelPay](/fr/papelpay/overview).
  </Step>
  <Step title="Confirmer le paiement">
    Ne vous fiez jamais au seul retour du client sur votre site. Écoutez le webhook `order.completed`, ou lisez la commande depuis votre serveur :

    ```bash
    curl https://app.papelship.com/api/v1/invoices/c35ffd-19a1b2c3d4e-8c7a20 \
      -H "x-api-key: pk_live_your_key" \
      -H "x-store-hash: your_store_id"
    ```

    La commande est payée et livrée lorsque `status` vaut `completed`.
  </Step>
</Steps>

<Warning>
  Conservez votre clé API sur votre serveur. Ne l'incluez jamais dans du code exécuté dans le navigateur, dans des applications mobiles ou dans des clients de bureau.
</Warning>
