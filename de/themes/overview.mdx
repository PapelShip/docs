## Theme-Kopien

Jedes Liquid Theme, jedes Design und jedes Theme-Code-Paket ist eine **Kopie** Ihres Shops. Ein Shop kann bis zu 20 Kopien behalten.

- Änderungen werden in der Kopie gespeichert, die Sie bearbeiten. Eine Kopie, die nicht live ist, verändert Ihre Storefront niemals.
- Die Live-Kopie ändert sich nur, wenn Sie sie im Panel veröffentlichen oder aktivieren.
- Jedes Speichern behält eine Version. Sie können jede der letzten 50 Versionen einer Datei wiederherstellen.

| Limit | Wert |
| --- | --- |
| Dateigröße | 512 KB |
| Dateien pro Kopie | 400 |
| Größe einer Kopie | 10 MB |
| Kopien pro Shop | 20 |

## Vorschauen

Vorschauen rendern Ihre gespeicherten Dateien und Ihre ungespeicherten Editor-Entwürfe innerhalb des Panels. Sie sind niemals öffentlich: Die Storefront zeigt eine nicht live geschaltete Kopie nur im Vorschau-Frame des Panels an, mit einem signierten Token, das nach 30 Minuten abläuft.

## Mit einem KI-Agenten arbeiten

Verbinden Sie Claude, Cursor, VS Code oder einen anderen MCP-Client mit Ihren Themes. Der Agent liest Ihren Theme-Code und speichert seine Änderungen als Entwürfe; Sie prüfen und veröffentlichen. Siehe [KI-Agenten (MCP)](/de/themes/mcp).
