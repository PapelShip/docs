Вбудовані теми Nightfall, Ship, Circuit, Arsenal, MarketPro та Vanguard залишаються без змін. Кодовий шар дає змогу додавати власний код поверх них і продовжувати редагувати візуально.

## Пакет коду теми

Кожен магазин отримує один **пакет коду теми** для кожної вбудованої теми. Ви відкриваєте його в редакторі коду так само, як будь-яку копію теми. Пакет містить лише:

| Папка | Містить |
| --- | --- |
| `sections/` | Кодові секції (`.liquid` із блоком `{% schema %}`) |
| `snippets/` | Часткові шаблони для ваших секцій |
| `assets/` | `theme.css`, що завантажується після стилів теми, і `theme.js`, що завантажується відкладено на сторінках теми |
| `locales/` | Переклади для ваших секцій |

JavaScript теми ніколи не завантажується на сторінках оформлення замовлення, входу чи облікового запису.

## Кодові секції у візуальному редакторі

Кожен файл `sections/<name>.liquid` із блоком `{% schema %}` з'являється у списку **Add section** візуального редактора в розділі **Theme code**. Форма його налаштувань будується зі схеми, тож кодову секцію можна повністю редагувати без коду. Зміна порядку, приховування, дублювання та видалення працюють так само, як для вбудованих секцій.

Коли ви змінюєте схему в коді, форма одразу оновлюється. Нові налаштування отримують значення за замовчуванням; видалені налаштування ігноруються, але їхні значення зберігаються.

## ID секцій у CSS

У кодовій секції `section.id` має значення `code:<name>`. Символ `:` ламає CSS-селектори (`#{{ section.id }}-yearly:checked` мовчки відкидається) і пошук за `#id`. Використовуйте `section.css_id` (`code-<name>`) у `{% style %}` та в атрибутах `id=` / `for=` або `{{ value | css_id }}`. Редактор коду та MCP-інструменти `validate` / `save_draft` попереджають про необроблений `section.id` у таких місцях; швидке виправлення в редакторі називається **Use section.css_id**.

Підписи, перемикачі radio/checkbox, `<details>` і випадаючі списки працюють на полотні візуального редактора. Щоб натискати посилання та кнопки, увімкніть **Interact** на верхній панелі (або натисніть `I`, чи утримуйте `Alt`).

## Редагування коду вбудованої секції

Оберіть **Edit code** для вбудованої секції, щоб виокремити її. Її Liquid-двійник копіюється до вашого пакета з тією самою розміткою та назвами класів, тож виглядає ідентично та зберігає свої налаштування. **Revert to built-in** повертає оригінальну секцію.

## Комерція та оформлення замовлення

Кодові секції продають за допомогою app blocks. Скрипти для цього не потрібні:

```liquid
{% app_block 'add_to_cart', product_id: product.id %}
{% app_block 'buy_now', product_id: product.id, mode: 'embed', label: 'Buy' %}
{% app_block 'checkout_button', mode: 'embed' %}
```

- `buy_now` і `checkout_button` за замовчуванням ведуть на сторінку оформлення замовлення. `mode: 'embed'` відкриває спливне вікно оформлення поверх вашої сторінки.
- `add_to_cart` і `cart_count` відкривають бічну панель кошика платформи. Значок кошика теми залишається синхронізованим.
- `reviews_widget` і `powered_by` не працюють у кодових секціях. `currency_selector` потребує `currencies: 'USD,EUR'`.
- Кодові секції мають `shop`, `collections`, `all_products`, `request` і `localization`. Вони не мають `product`, `collection` чи `routes`.
- `window.PapelShip` завантажується після завантаження сторінки на тих сторінках, чиї кодові секції містять app block або прив'язку `data-ps`. У `assets/theme.js` дочекайтеся `papelship:sdk-ready`.

Див. [Комерція та оформлення замовлення](/uk/themes/commerce) і [App blocks](/uk/themes/app-blocks).

## Публікація

Активні сторінки показують **опубліковану** версію пакета. Збережені файли відображаються лише в попередньому перегляді візуального редактора та редактора коду.

1. Редагуйте й зберігайте файли в редакторі коду або дозвольте AI-агенту зберігати чернетки.
2. Перевірте попередній перегляд.
3. Натисніть **Publish** у редакторі коду або візуальному редакторі. Це та сама кнопка, і вона показує, скільки змін ще не опубліковано.

Під час публікації спершу перевіряється кожен файл пакета. Якщо щось не проходить перевірку, в активному магазині нічого не змінюється.

<Note>
  AI-агенти, підключені через MCP, можуть зберігати файли пакета, але ніколи не публікують їх. Див. [AI-агенти (MCP)](/uk/themes/mcp).
</Note>

## Безпека

Файли пакета скануються так само, як дизайни: і вихідний код, і відрендерений результат. Налаштування із форматованим текстом і HTML очищаються на сервері.
