Встроенные темы Nightfall, Ship, Circuit, Arsenal, MarketPro и Vanguard остаются в точности такими же. Слой кода позволяет добавлять поверх них собственный код и продолжать редактировать визуально.

## Пакет кода темы

Каждый магазин получает по одному **пакету кода темы** на каждую встроенную тему. Он открывается в редакторе кода так же, как любая копия темы. Пакет содержит только:

| Папка | Содержимое |
| --- | --- |
| `sections/` | Секции кода (`.liquid` с блоком `{% schema %}`) |
| `snippets/` | Частичные шаблоны для ваших секций |
| `assets/` | `theme.css`, который загружается после стилей темы, и `theme.js`, который загружается отложенно на страницах темы |
| `locales/` | Переводы для ваших секций |

JavaScript темы никогда не загружается на страницах оформления заказа, входа или аккаунта.

## Секции кода в визуальном редакторе

Каждый файл `sections/<name>.liquid` с блоком `{% schema %}` появляется в списке **Добавить секцию** визуального редактора в разделе **Код темы**. Форма его настроек строится по схеме, поэтому секцию кода можно полностью редактировать без кода. Перестановка, скрытие, дублирование и удаление работают так же, как для встроенных секций.

Когда вы меняете схему в коде, форма обновляется сразу. Новые настройки получают значения по умолчанию; удаленные настройки игнорируются, а их значения сохраняются.

## ID секций в CSS

В секции кода `section.id` имеет вид `code:<name>`. Символ `:` ломает CSS-селекторы (`#{{ section.id }}-yearly:checked` молча отбрасывается) и поиск по `#id`. Используйте `section.css_id` (`code-<name>`) в `{% style %}` и в атрибутах `id=` / `for=` или `{{ value | css_id }}`. Редактор кода и MCP-инструменты `validate` / `save_draft` предупреждают о необработанном `section.id` в таких местах; быстрое исправление в редакторе называется **Использовать section.css_id**.

Метки, переключатели radio/checkbox, `<details>` и списки select работают на холсте визуального редактора. Чтобы нажимать на ссылки и кнопки, включите **Взаимодействие** на верхней панели (или нажмите `I`, или удерживайте `Alt`).

## Редактирование кода встроенной секции

Выберите **Редактировать код** для встроенной секции, чтобы выделить ее. Ее Liquid-двойник копируется в ваш пакет с той же разметкой и именами классов, поэтому он выглядит так же и сохраняет свои настройки. **Вернуть встроенную** восстанавливает исходную секцию.

## Коммерция и оформление заказа

Секции кода продают с помощью блоков приложений. Скрипт для этого не нужен:

```liquid
{% app_block 'add_to_cart', product_id: product.id %}
{% app_block 'buy_now', product_id: product.id, mode: 'embed', label: 'Buy' %}
{% app_block 'checkout_button', mode: 'embed' %}
```

- `buy_now` и `checkout_button` по умолчанию ведут на страницу оформления заказа. `mode: 'embed'` открывает всплывающее окно оформления поверх вашей страницы.
- `add_to_cart` и `cart_count` открывают выдвижную панель корзины платформы. Значок корзины темы остается синхронизированным.
- `reviews_widget` и `powered_by` не работают в секциях кода. Для `currency_selector` нужен `currencies: 'USD,EUR'`.
- В секциях кода доступны `shop`, `collections`, `all_products`, `request` и `localization`. В них нет `product`, `collection` и `routes`.
- `window.PapelShip` загружается после загрузки страницы на страницах, секции кода которых содержат блок приложения или привязку `data-ps`. В `assets/theme.js` дождитесь события `papelship:sdk-ready`.

См. [Коммерция и оформление заказа](/ru/themes/commerce) и [Блоки приложений](/ru/themes/app-blocks).

## Публикация

Рабочие страницы показывают **опубликованную** версию пакета. Сохраненные файлы отображаются только в предпросмотре визуального редактора и редактора кода.

1. Редактируйте и сохраняйте файлы в редакторе кода или позвольте ИИ-агенту сохранять черновики.
2. Проверьте предпросмотр.
3. Нажмите **Опубликовать** в редакторе кода или визуальном редакторе. Это одна и та же кнопка, она показывает количество неопубликованных изменений.

Перед публикацией проверяется каждый файл пакета. Если что-то не проходит проверку, в рабочем магазине ничего не меняется.

<Note>
  ИИ-агенты, подключенные через MCP, могут сохранять файлы пакета, но никогда не публикуют их. См. [ИИ-агенты (MCP)](/ru/themes/mcp).
</Note>

## Безопасность

Файлы пакета сканируются так же, как дизайны: и исходный код, и отрисованный результат. Настройки с форматированным текстом и HTML очищаются на сервере.
