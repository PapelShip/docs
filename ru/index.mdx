## Начните разработку

<Steps>
  <Step title="Получите API-ключ">
    Войдите в [панель управления PapelShip](https://app.papelship.com) и создайте API-ключ для своего магазина.
  </Step>
  <Step title="Отправьте первый запрос">
    Следуйте [краткому руководству](/ru/quickstart), чтобы создать первый заказ и направить клиента на страницу оплаты.
  </Step>
  <Step title="Запустите в продакшен">
    Перед запуском изучите разделы [аутентификация](/ru/guides/authentication), [ошибки](/ru/guides/errors) и [идемпотентность](/ru/guides/idempotency).
  </Step>
</Steps>

## Базовые URL

| API | Базовый URL |
| :-- | :-- |
| User API | `https://app.papelship.com/api/v1` |
| qPapel Protection | `https://app.papelship.com/api/qpapel/v1` |

<Info>
  Все API принимают и возвращают JSON по HTTPS. Запросы по обычному HTTP не поддерживаются.
</Info>
