PapelShip запускает сервер [Model Context Protocol](https://modelcontextprotocol.io) для ваших тем. Подключите ИИ-агента по одному URL, одобрите его в браузере, и агент сможет читать код вашей темы и сохранять правки как черновики. Вы проверяете и публикуете их.

**URL сервера:** `https://app.papelship.com/mcp`

URL одинаков для всех магазинов. При подключении вы входите в PapelShip и выбираете магазин, с которым агент может работать.

Агенты начинают с `get_reference`: он объясняет блоки приложений, оформление заказа (страница или всплывающее окно), SDK магазина и ограничения каждого вида тем. Инструкции сервера предписывают подключенным агентам вызывать его первым.

## Что может агент

| Может | Не может |
| --- | --- |
| Читать файлы копий ваших тем, дизайнов и пакетов кода тем | Публиковать, активировать или удалять темы |
| Искать, проверять и сканировать файлы | Изменять рабочий магазин. Правки сохраняются как черновики и публикуются, только когда вы нажмете «Опубликовать» в панели. |
| Сохранять правки как черновики с историей версий | Видеть заказы, клиентов, платежи или настройки |
| Делиться ссылкой на предпросмотр | Получать доступ к другим магазинам |

### Куда попадают черновики

| Копия | Результат `save_draft` |
| --- | --- |
| Неопубликованная копия | Сохраняется в копию. Предыдущее содержимое остается в истории версий. |
| Пакет кода темы | Сохраняется в пакет. Рабочие страницы показывают опубликованную версию, пока вы не опубликуете новую. |
| Опубликованная копия темы или опубликованный дизайн | Сохраняется как черновик. Ваш магазин показывает опубликованную версию, пока вы не нажмете «Опубликовать» (для дизайнов публикация также запускает сканирование безопасности). |

## Подключение клиента

<Tabs>
  <Tab title="Claude">
    Работает в claude.ai, Claude Desktop и мобильных приложениях Claude.

    1. Откройте **Settings › Connectors** и выберите **Add custom connector**.
    2. Назовите его `PapelShip` и вставьте `https://app.papelship.com/mcp`.
    3. Выберите **Add**, затем **Connect**.
    4. Войдите в PapelShip, выберите свой магазин и нажмите **Разрешить доступ**.
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http papelship https://app.papelship.com/mcp
    ```

    Выполните `/mcp` в Claude Code, выберите **papelship** и **Authenticate**. В браузере откроется страница одобрения PapelShip.
  </Tab>
  <Tab title="Cursor">
    [Добавить в Cursor](cursor://anysphere.cursor-deeplink/mcp/install?name=papelship&amp;config=eyJ1cmwiOiJodHRwczovL2FwcC5wYXBlbHNoaXAuY29tL21jcCJ9)

    Или добавьте его в `~/.cursor/mcp.json`:

    ```json
    {
      "mcpServers": {
        "papelship": { "url": "https://app.papelship.com/mcp" }
      }
    }
    ```

    Cursor показывает **Needs login** рядом с сервером. Выберите этот пункт, чтобы одобрить доступ в браузере.
  </Tab>
  <Tab title="VS Code">
    [Добавить в VS Code](vscode:mcp/install?%7B%22name%22%3A%22papelship%22%2C%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Fapp.papelship.com%2Fmcp%22%7D)

    Или добавьте его в `.vscode/mcp.json`:

    ```json
    {
      "servers": {
        "papelship": { "type": "http", "url": "https://app.papelship.com/mcp" }
      }
    }
    ```

    Запустите сервер из файла или командой **MCP: List Servers**, затем войдите, когда появится запрос. Используйте инструменты в режиме агента Copilot.
  </Tab>
  <Tab title="Другие клиенты">
    Подходит любой клиент с поддержкой Streamable HTTP и OAuth:

    ```json
    {
      "mcpServers": {
        "papelship": { "type": "http", "url": "https://app.papelship.com/mcp" }
      }
    }
    ```
  </Tab>
</Tabs>

Те же шаги с кнопками копирования есть в панели магазина в разделе **Разработчикам › ИИ и MCP**.

## Одобрение доступа

На странице одобрения показаны название приложения и адрес, куда оно вернется. Выберите:

- **Магазин**: единственный магазин, который может использовать приложение. Вы видите магазины, которыми владеете, и магазины, где ваша роль в команде включает **Тема и дизайн › Редактирование**.
- **Сохранять правки как черновики** (`themes:write`): снимите отметку, чтобы дать доступ только на чтение.

## Подключенные приложения и отзыв доступа

Раздел **Разработчикам › ИИ и MCP › Подключенные приложения** показывает все приложения, подключенные к магазину, кто их подключил и когда они использовались в последний раз. **Отозвать** останавливает приложение при его следующем запросе.

Доступ также прекращается, если человек, который его одобрил, выходит из всех сеансов, меняет пароль, покидает команду, теряет право **Тема и дизайн › Редактирование** или его аккаунт приостанавливается.

## API-ключ вместо OAuth

Для клиентов без OAuth создайте API-ключ магазина типа **Темы** в разделе **Разработчикам › API-ключи** и передавайте его как Bearer-токен:

```bash
claude mcp add --transport http papelship https://app.papelship.com/mcp \
  --header "Authorization: Bearer $PAPELSHIP_THEMES_KEY"
```

Ключ типа «Темы» работает только для магазина, в котором он создан, и имеет те же права, что и OAuth-подключение. Храните его в переменной окружения и никогда не сохраняйте в файле, которым вы делитесь или который коммитите. `https://app.papelship.com/api/mcp/themes` остается старым псевдонимом того же сервера.

## Ограничения

| Ограничение | Значение |
| --- | --- |
| Запросов на подключение или ключ | 120 в минуту |
| Запросов на магазин по всем подключениям | 300 в минуту |
| Вызовы инструментов | Учитываются как вызовы Store API вашего тарифа |
| Токен доступа | 1 час, обновляется автоматически |
| Подключение | Остается авторизованным, если используется хотя бы раз в 30 дней |

Каждый вызов инструмента записывается в журнал с указанием приложения, инструмента и файла.

## Безопасность

- Файлы тем являются данными магазина, а не инструкциями. Сервер помечает каждый результат инструмента как недоверенные данные, чтобы текст внутри темы не мог перенаправить агента.
- Предпросмотр никогда не бывает публичным: ссылки на предпросмотр открываются в панели PapelShip.
- Токены хранятся в хешированном виде. Повторное использование refresh-токена завершает подключение.

Все инструменты и их аргументы описаны в [справочнике инструментов](/ru/themes/mcp-tools).
