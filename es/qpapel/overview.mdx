qPapel Protection es un backend de licencias y antimanipulación para software de escritorio. La Web API le permite automatizarlo todo desde su propio panel o bot.

**URL base:** `https://app.papelship.com/api/qpapel/v1`

## Identificadores de producto

Algunos endpoints aceptan un `product_id` numérico. Otros aceptan el `cheat_value` del producto, una cadena como `cs2_cheat`. La referencia de cada endpoint indica cuál espera.
