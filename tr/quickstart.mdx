title: "Hızlı başlangıç"
description: "PapelShip Store API ile ilk siparişinizi oluşturun, müşteriyi ödeme sayfasına gönderin ve ödemeyi webhook ya da sipariş okuyarak doğrulayın."
---

Bu rehber PapelShip Store API ile uçtan uca bir siparişi anlatır: ürünlerinizden biri için sipariş oluşturun, müşteriyi barındırılan ödeme sayfasına gönderin ve ödemeye güvenmeden önce doğrulayın.

## Gereksinimler

- En az bir ürünü olan bir PapelShip mağazası
- `orders:write` iznine sahip bir Store API anahtarı (`pk_live_...`) ve `x-store-hash` header'ı için mağaza kimliğiniz

<Tip>
  İkisini de [PapelShip panelinde](https://app.papelship.com) mağazanızın API ayarları altında bulabilirsiniz. Bkz. [Kimlik doğrulama](/tr/guides/authentication).
</Tip>

<Steps>
  <Step title="Sipariş oluşturun">
    Müşterinin e-postasını ve ürünleri gönderin. Tekrar denemelerde ikinci bir sipariş oluşmaması için `Idempotency-Key` header'ı ekleyin.

    <CodeGroup>
    ```bash cURL
    curl -X POST https://app.papelship.com/api/v1/invoices \
      -H "x-api-key: pk_live_anahtariniz" \
      -H "x-store-hash: magaza_kimliginiz" \
      -H "Idempotency-Key: WEB-1042" \
      -H "Content-Type: application/json" \
      -d '{
        "customer_email": "alici@example.com",
        "items": [{ "product_id": "a1B2c3D4e5F6", "quantity": 1 }],
        "metadata": { "order_ref": "WEB-1042" }
      }'
    ```

    ```javascript Node.js
    const res = await fetch("https://app.papelship.com/api/v1/invoices", {
      method: "POST",
      headers: {
        "x-api-key": process.env.PAPELSHIP_API_KEY,
        "x-store-hash": process.env.PAPELSHIP_STORE_ID,
        "Idempotency-Key": order.id,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        customer_email: order.email,
        items: [{ product_id: "a1B2c3D4e5F6", quantity: 1 }],
        metadata: { order_ref: order.id },
      }),
    });
    const { invoice } = await res.json();
    ```

    ```python Python
    import os, requests
    
    res = requests.post(
        "https://app.papelship.com/api/v1/invoices",
        headers={
            "x-api-key": os.environ["PAPELSHIP_API_KEY"],
            "x-store-hash": os.environ["PAPELSHIP_STORE_ID"],
            "Idempotency-Key": order_id,
        },
        json={
            "customer_email": "alici@example.com",
            "items": [{"product_id": "a1B2c3D4e5F6", "quantity": 1}],
            "metadata": {"order_ref": order_id},
        },
    )
    invoice = res.json()["invoice"]
    ```
    </CodeGroup>
  </Step>

  <Step title="Müşteriyi ödeme sayfasına gönderin">
    Cevapta `checkout_url` ile birlikte sipariş gelir. Müşteriyi, mağazanızın kabul ettiği herhangi bir yöntemle ödemesi için bu adrese yönlendirin.

    ```json Cevap (201)
    {
      "success": true,
      "invoice": {
        "id": "c35ffd-19a1b2c3d4e-8c7a20",
        "status": "pending",
        "currency": "USD",
        "total_cents": 3499,
        "checkout_url": "https://invoice.papelship.com/c35ffd-19a1b2c3d4e-8c7a20",
        "expires_at": "2026-10-04T15:00:00.000Z"
      }
    }
    ```

    `invoice.id` değerini siparişinizle saklayın. Ödenmeyen siparişlerin süresi 3 saatte dolar. Kartı hemen çekmek ya da kart formunu kendi sitenizde göstermek için bkz. [PapelPay](/tr/papelpay/overview).
  </Step>

  <Step title="Ödemeyi doğrulayın">
    Yalnızca müşterinin sitenize dönmesine güvenmeyin. `order.completed` webhook'unu dinleyin ya da siparişi sunucunuzda okuyun:

    ```bash
    curl https://app.papelship.com/api/v1/invoices/c35ffd-19a1b2c3d4e-8c7a20 \
      -H "x-api-key: pk_live_anahtariniz" \
      -H "x-store-hash: magaza_kimliginiz"
    ```

    `status` değeri `completed` olduğunda sipariş ödenmiş ve teslim edilmiştir.
  </Step>
</Steps>

<Warning>
  API anahtarınızı sunucuda tutun. Asla tarayıcı koduna, mobil uygulamalara veya masaüstü istemcilere gömmeyin.
</Warning>
