qPapel Protection est un backend de gestion des licences et de protection contre la falsification pour les logiciels de bureau. La Web API vous permet de tout automatiser depuis votre propre panneau ou votre propre bot.

**URL de base :** `https://app.papelship.com/api/qpapel/v1`

## Identifiants de produit

Certains points de terminaison acceptent un `product_id` numérique. D'autres acceptent le `cheat_value` du produit, une chaîne comme `cs2_cheat`. La référence de chaque point de terminaison indique lequel il attend.
