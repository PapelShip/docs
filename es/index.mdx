## Empiece a construir

<Steps>
  <Step title="Obtenga su clave de API">
    Inicie sesión en el [panel de PapelShip](https://app.papelship.com) y cree una clave de API para su tienda.
  </Step>
  <Step title="Haga su primera solicitud">
    Siga la [guía de inicio rápido](/es/quickstart) para crear su primer pedido y enviar al cliente al checkout.
  </Step>
  <Step title="Pase a producción">
    Revise [autenticación](/es/guides/authentication), [errores](/es/guides/errors) e [idempotencia](/es/guides/idempotency) antes de lanzar.
  </Step>
</Steps>

## URL base

| API | URL base |
| :-- | :-- |
| User API | `https://app.papelship.com/api/v1` |
| qPapel Protection | `https://app.papelship.com/api/qpapel/v1` |

<Info>
  Todas las API aceptan y devuelven JSON a través de HTTPS. No se admiten solicitudes por HTTP sin cifrar.
</Info>
