ИИ-агенты получают тот же справочник из MCP тем: инструмент `get_reference` (тема `app_blocks`) и ресурс `papelship://reference/app-blocks`. Редактор кода, `validate` и `save_draft` предупреждают о неизвестных блоках, неизвестных или неверно типизированных аргументах и блоках, которые данный вид темы не поддерживает.

Блоки платформы (`{% app_block %}` / data-app-block): аргументы, поведение, поддержка по видам тем; заблокированные блоки страниц.

```liquid
{% app_block 'buy_now', product_id: product.id, mode: 'embed' %}
```

```html
<div data-app-block="buy_now" data-props='{"product_id":"PRODUCT_ID","mode":"embed"}'></div>
```

`да*`: работает, с примечанием ниже. В секциях кода и выделенных двойниках блоки корзины используют выдвижную панель корзины платформы, а не собственную панель React-темы; значок корзины темы остается синхронизированным.

## add_to_cart

Кнопка добавления в корзину для одного товара. Добавляет товар в общую корзину витрины и открывает выдвижную панель корзины. Если у товара несколько вариантов и ни один не выбран, выбор запрашивает variant_picker рядом с ней, иначе открывается страница товара.

| Аргумент | Тип | Обязателен | Псевдонимы | По умолчанию | Описание |
| --- | --- | --- | --- | --- | --- |
| `product_id` | product | да | `product` |  | ID или хеш-ID товара (product.id / product.hash_id). Также принимается объект товара. |
| `variant_id` | id |  | `variant` |  | ID варианта; по умолчанию используется вариант, выбранный в variant_picker рядом, иначе вариант по умолчанию. |
| `quantity` | integer |  |  | `1` | Количество (1 или больше). |
| `label` | string |  |  |  | Текст кнопки (по умолчанию "Add to cart" с переводом). Игнорируется, если у заполнителя есть собственная разметка. |
| `mode` | enum (`page`, `embed`) |  |  |  | Не действует: add_to_cart всегда добавляет в корзину. Для оформления заказа используйте buy_now. |

## buy_now

Кнопка покупки в один клик для одного товара. `mode: 'page'` (по умолчанию) ведет на оформление заказа платформы только с этим товаром (корзина сохраняется). `mode: 'embed'` открывает всплывающее окно оформления поверх страницы (iframe платформы; данные карты никогда не попадают в тему) и переходит на страницу, если виджет не удается загрузить.

| Аргумент | Тип | Обязателен | Псевдонимы | По умолчанию | Описание |
| --- | --- | --- | --- | --- | --- |
| `product_id` | product | да | `product` |  | ID или хеш-ID товара. Также принимается объект товара. |
| `variant_id` | id |  | `variant` |  | ID варианта; по умолчанию используется вариант, выбранный в variant_picker рядом. |
| `quantity` | integer |  |  | `1` | Количество (1 или больше). |
| `label` | string |  |  |  | Текст кнопки (по умолчанию "Buy now" с переводом). |
| `mode` | enum (`page`, `embed`) |  |  | `page` | `page` = страница оформления заказа; `embed` = всплывающее окно оформления поверх текущей страницы. |

## cart_count

Кнопка корзины с количеством товаров ("Cart `<n>`"); ваша собственная разметка сохраняет свой вид, а дочерний элемент `[data-ps-count]` получает число. Нажатие открывает выдвижную панель корзины. Аргументов нет.

## cart_drawer

Настраивает выдвижную панель корзины (позиции, количества, скидки по акциям, шкала бесплатной доставки, допродажи, оформление заказа). Ничего не отрисовывает на месте; первый `cart_drawer` на странице задает параметры.

| Аргумент | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `upsell` | string |  | Handle или id коллекции, товары которой предлагаются в панели. |
| `upsell_limit` | integer | `3` | Количество показываемых товаров для допродажи (от 1 до 6). |
| `upsell_heading` | string |  | Заголовок блока допродаж (по умолчанию "You may also like"). |
| `free_shipping` | boolean | `true` | `false` скрывает шкалу прогресса бесплатной доставки. |

## checkout_button

Кнопка оформления заказа для всей корзины (неактивна, пока корзина пуста). `mode: 'page'` (по умолчанию) ведет на `<store>/checkout`; `mode: 'embed'` открывает всплывающее окно оформления; после оплаты корзина очищается.

| Аргумент | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `label` | string |  | Текст кнопки (по умолчанию "Checkout" с переводом). |
| `mode` | enum (`page`, `embed`) | `page` | Страница оформления заказа или всплывающее окно. |

## currency_selector

Выбор валюты отображения (скрыт, если валют меньше двух). Сохраняет валюту отображения (оплата всегда списывается в валюте магазина) и генерирует событие `papelship:currency-change`. В секциях кода и двойниках передавайте `currencies`: эти страницы знают только валюту магазина.

| Аргумент | Тип | Описание |
| --- | --- | --- |
| `label` | string | Текст метки. |
| `currencies` | list | Коды валют (`"USD,EUR,TRY"` или массив); по умолчанию валюты отображения магазина. |

## language_selector

Выбор языка магазина (скрыт, если у магазина один язык). Устанавливает cookie языка и перезагружает страницу. Аргумент: `label`.

## newsletter_form

Подписка на рассылку с явным флажком согласия. Отправляет данные на эндпоинт лидов платформы; в предпросмотре подписка никогда не оформляется. Аргументы: `label`, `placeholder`, `button`, `consent_text`.

## powered_by

Подпись "Powered by PapelShip" (скрыта на тарифах, которые позволяют ее скрывать). Только для тем Liquid: страницы дизайнов и подвалы React-тем получают подпись от платформы автоматически.

## quick_view

Кнопка быстрого просмотра одного товара: открывает диалог с изображениями, ценой, вариантами и кнопкой добавления в корзину. Аргументы: `product_id` (обязательный, псевдоним `product`), `label`.

## recently_viewed

Недавно просмотренные посетителем товары (из этого браузера); ничего не отрисовывает, если список пуст. Товары записываются на страницах товаров Liquid (страницы товаров React-тем просмотры не записывают). Аргументы: `limit` (по умолчанию 4, от 1 до 20), `heading`.

## reviews_widget

Опубликованные отзывы: о товаре на страницах товаров, иначе о магазине. Не поддерживается в секциях кода и двойниках (на этих страницах нет данных отзывов; используйте секцию отзывов React-темы). Аргументы: `heading`, `limit` (по умолчанию 5, от 1 до 50), `write` (по умолчанию `true`; `false` скрывает ссылку «написать отзыв»).

## variant_picker

Выбор варианта (группы переключателей) для одного товара. `add_to_cart` / `buy_now` того же товара в ближайшем общем контейнере (или элементе `data-ps-scope`) используют выбранный вариант; тексты `data-ps` price / compare-price / stock следуют за ним. Аргумент: `product_id` (обязательный, псевдоним `product`).

## wishlist_button

Переключатель избранного для одного товара (кнопка в виде сердца с `aria-pressed`). Сохраняется в браузере и синхронизируется с аккаунтом клиента после входа. Аргумент: `product_id` (числовой id; хеш-ID не сохраняются в аккаунте).

## Заблокированные блоки страниц

| Блок | Страница | Файл темы Liquid | Файл дизайна |
| --- | --- | --- | --- |
| `checkout_form` | Страница оформления заказа | `templates/checkout.liquid` | `pages/checkout.liquid` или `.html` |
| `cart_view` | Страница корзины | `templates/cart.liquid` | `pages/cart.liquid` или `.html` |
| `customer_login` | Страница входа | `templates/customers/login.liquid` | `pages/login.liquid` или `.html` |
| `customer_account` | Страница аккаунта | `templates/customers/account.liquid` | `pages/account.liquid` или `.html` |
| `order_track` | Страница отслеживания заказа | `templates/customers/track.liquid` | `pages/track.liquid` или `.html` |

Каждый из них работает только один раз, в своем собственном файле переопределения. В пакетах кода React-тем переопределений страниц нет.
