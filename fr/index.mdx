## Commencer à développer

<Steps>
  <Step title="Obtenez votre clé API">
    Connectez-vous au [tableau de bord PapelShip](https://app.papelship.com) et créez une clé API pour votre boutique.
  </Step>
  <Step title="Envoyez votre première requête">
    Suivez le [guide de démarrage rapide](/fr/quickstart) pour créer votre première commande et rediriger le client vers le paiement.
  </Step>
  <Step title="Passez en production">
    Consultez les pages [authentification](/fr/guides/authentication), [erreurs](/fr/guides/errors) et [idempotence](/fr/guides/idempotency) avant la mise en ligne.
  </Step>
</Steps>

## URL de base

| API | URL de base |
| :-- | :-- |
| User API | `https://app.papelship.com/api/v1` |
| qPapel Protection | `https://app.papelship.com/api/qpapel/v1` |

<Info>
  Toutes les API acceptent et renvoient du JSON via HTTPS. Les requêtes en HTTP simple ne sont pas prises en charge.
</Info>
