qPapel Protection є бекендом для ліцензування та захисту від втручання для десктопного програмного забезпечення. Web API дає змогу автоматизувати все зі своєї власної панелі або бота.

**Базовий URL:** `https://app.papelship.com/api/qpapel/v1`

## Ідентифікатори продуктів

Деякі ендпоінти приймають числовий `product_id`. Інші приймають `cheat_value` продукту, рядок на кшталт `cs2_cheat`. У довіднику кожного ендпоінта вказано, який саме він очікує.
