User API, mağaza sahiplerine paneldeki her şeye programatik erişim sağlar.

**Base URL:** `https://app.papelship.com/api_user/api/v1`

`x-api-key` ve `x-store-hash` header'larıyla kimlik doğrulayın. Bkz. [Kimlik doğrulama](/tr/guides/authentication).

## Fiyatlar kuruş (cent) cinsindendir

Tüm `*_cents` alanları en küçük para birimi cinsinden tam sayıdır. Örneğin `price_cents: 2999` değeri $29.99 demektir.

## Sayfalama

`GET /products` gibi liste endpoint'leri `limit` (varsayılan `50`) ve `offset` (varsayılan `0`) kabul eder:

```bash
curl "https://app.papelship.com/api_user/api/v1/products?limit=50&offset=100&status=active" \
  -H "x-api-key: your_api_key" \
  -H "x-store-hash: your_store_hash"
```
